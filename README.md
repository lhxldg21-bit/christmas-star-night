# 给 TA 的一场雪夜迎接 · 可操作样片

可定制、可售卖的 Three.js 圣诞告白微体验的第一个可操作样片。
覆盖验收点：拾起/翻看星星、狐狸先跑—折返—并肩、脚印与足音同步、
逐盏点灯与拉镜、两份不同定制配置从第一天读取。

## 运行

```bash
npm install
npm run dev        # 开发预览
npm run build      # 产物在 dist/（纯静态，可任意静态托管）
```

打开后点击「开启这份礼物」开始（同时解锁音频）。
`?auto=1` 为自动演示模式（84 秒循环重放整条旅程；用于覆盖完整交互节拍）。

## 两份样片配置（定制能力的验收）

- 配置 A（默认）：`index.html` 或 `#demo=a`
- 配置 B（换称呼、换短句、整封信重写）：`#demo=b`
- 任意定制：`#c=<base64url(JSON)>`，字段见 `src/config.js`
  （toName / fromName / note / starText / walkLine / activity / letter / theme）。
  留空字段回落默认稿，界面永不出现占位括号。

## 技术要点

- 纯程序化生成：地形、松树、人物、狐狸、星星、雪、音频全部为代码生成，
  无第三方素材，无授权风险（BGM 为 WebAudio 生成的冬夜钢琴/钟琴分层）。
- 场景随机性全部走种子 PRNG（`mulberry32(20261225)`），任何一帧可用
  `?capture=1&t=<秒>` 确定性复现；自动模式 t=0 与 t=46s 像素一致。
- 脚印/爪印为 InstancedMesh 池，按真实落脚事件生成；脚步声同步触发，
  狐狸远近衰减。
- 性能：峰值约 85 draw calls / 3 万三角形，移动端竖屏已验证。
